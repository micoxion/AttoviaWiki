An **Exouse** Ledger is shaped like a small, triangular pillar with four metal walls which surround a [[Minor Stone]]. On the underside is a raised cylinder, which upon depression completes a set of [[Orchid Script]]. This Script informs the Minor Stone to begin absorbing and storing information about surrounding changes in pressure. If twisted 90 degrees then pressed flush to the base again, it will regurgitate the last recording. Any time the **Exouse** Ledger is used to record it overwrites the previously stored information. However, the last stored recording can be of nearly infinite length, and played back forever without loss. The most common use of the Exouse Ledger's is contractual agreements and training recordings, usually sealing the base so that it cannot be overwritten easily. They may also be coupled with [[Proicho Machina]] which can then blast the recording at much higher volumes where it might be needed.
